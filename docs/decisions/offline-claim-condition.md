# "오프라인에서도 된다"는 저장된 환율이 있을 때로 한정해 말한다

- 정한 날: 2026-10-29
- 근거: #96(Play 문구), #97(App Store 문구), 2026-10-29 실기기 확인
- 적용: 스토어 등록 문구, 스토어 이미지, 소개 글

## 규칙

- "오프라인에서도 사용 가능"에는 "환율을 한 번 받아 두면" 같은 조건을 붙인다. 이미지 문구도 "저장된 환율로",
  "출국 전에 한 번 열어 두면"처럼 조건을 담는다.
- 환율 기준일을 "항상" 보여 준다고 쓰지 않는다. 기준일은 환율·즐겨찾기 화면에만 나오고 계산기 화면에는 없다.

## 이유

- 앱은 Firestore 문서를 받아 로컬에 저장하고(12시간 TTL), 원격 조회가 실패하면 저장된 환율을 쓴다.
  저장된 환율이 없으면 오류를 낸다(Android `ExchangeRateRepositoryImpl`). 설치 직후 연결 없이 처음 열면 환산할 수 없다.
- 2026-10-29 Note20 실기기의 비행기 모드에서 앱을 새로 열어도, 저장된 환율(기준일 2026.10.22)로 바로 환산되는 것을
  확인했다.

## 확인 방법

- 자동 검증은 아직 없다. 문구를 다시 쓰거나 캐시 동작을 바꾸면 실기기 비행기 모드로 다시 확인한다.
