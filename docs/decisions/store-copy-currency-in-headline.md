# 여러 나라가 보는 스토어 제목에 특정 통화를 앞세우지 않는다

- 정한 날: 2026-10-29
- 근거: #97, 2026-10-29 대화
- 적용: 영어 스토어 이미지(Play, App Store iPhone·iPad)와 등록 문구

## 규칙

- 영어 세트처럼 여러 나라 사람이 보는 이미지의 큰 제목에 `¥` 같은 특정 나라 통화를 넣지 않는다.
  예: "What's ¥1,980 in dollars?" → "How much is it in dollars?"
- 화면 속 예시로 그 통화를 쓰는 것은 괜찮다. 제목 때문에 특정 나라 여행 앱처럼 보이지 않게 하는 것이 목적이다.

## 이유

- 큰 제목의 엔화 예시 때문에 일본 여행용 앱처럼 보였다. 앱은 160여 개 통화를 다룬다.

## 예외

- 한국어 세트 01 "엔화 가격, 원화로 얼마지?"는 그대로 둔다. 이 세트는 일본 여행을 가는 한국인을 첫 타깃으로 잡은
  시작 가설이다(`store-assets/travel-ko-20261022/launch-copy-ko.txt`). 타깃을 바꾸면 이 예외도 다시 본다.
