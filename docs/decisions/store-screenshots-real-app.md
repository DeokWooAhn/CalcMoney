# 스토어 이미지는 실제 앱 화면을 찍어 만들고 값을 합성하지 않는다

- 정한 날: 2026-10-22
- 근거: `store-assets/travel-ko-20261022/launch-copy-ko.txt`의 "게시 전 확인", #96
- 적용: Play·App Store 스크린샷, 피처 그래픽

## 규칙

- 화면은 실제 앱을 조작해 찍는다. 환율이나 계산 결과를 합성하지 않는다. 설명 문구와 배경만 따로 만든다.
- 플랫폼마다 그 플랫폼의 실제 화면을 따로 찍는다. Android 화면을 App Store에 쓰지 않는다.
- 화면의 환산 값은 촬영 시점에 저장돼 있던 환율이다. 최신 시세나 실제 카드 청구액이라고 쓰지 않는다.
- 촬영 조건이 실제 사용과 다르면 이미지에 적는다. 예: 시뮬레이터에는 비행기 모드가 없어 원격 데이터 소스를 끊은
  실행으로 찍은 App Store 오프라인 이미지에는 "서버 연결 없이 촬영"이라고 적었다(#96).

## 이유

- 스토어 이미지는 앱이 실제로 하는 일을 보여 주는 약속이다. 합성한 값은 앱이 그 값을 낸다는 보장이 없다.
- 환율은 매일 바뀐다. 이미지의 값을 지금 시세처럼 말하면 사용자가 보는 값과 어긋난다.
