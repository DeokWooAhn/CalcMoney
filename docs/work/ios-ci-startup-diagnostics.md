# iOS CI 시작 실패와 진단 수집

- 목표: 머지 후 고정 환율 Flow의 첫 화면 진입 실패를 재현·수정하고, 실패해도 앱·시뮬레이터·크래시 진단을 보관한다.
- 범위: iOS Maestro 실행·진단 스크립트와 CI, 재현에 필요한 테스트 초기화, 안내 문서. 기존 사용자 파일과 배포 설정은 유지한다.
- 검증: 실패 기록과 같은 순서로 앱을 반복 시작하고 smoke 전체를 실행한다. 진단 수집의 정상·명령 실패·시간 초과를 검사하고, 작업 브랜치·PR·머지 커밋의 CI를 확인한다.
- 완료: 두 번의 연속 smoke, CI·리뷰 확인 후 PR 머지, 기본 브랜치 CI 확인·로컬 최신화·작업 브랜치 정리.
- 근거: 실패 실행 43573583015의 고정 환율 Flow는 `clearState` 실행 직후 2.4초 만에 앱 종료로 판정됐지만, 같은 PID는 그 뒤에도 UIKit 초기화를 계속했다. 재설치 직후 실행 상태 경합을 피하도록 앱이 테스트 상태를 초기화한다. 실제 크래시였다고 단정하지 않는다.
- 로컬 확인: 새 초기화 옵션 3개와 기존 AppContainer 검사, UI 테스트, SwiftLint·SwiftFormat, 진단 회귀 검사 4개 통과. smoke 4개가 두 번 연속 통과했고 진단 명령 5개도 모두 성공했다. CI·리뷰·머지 확인은 PR과 연결된 GitHub 실행 결과를 따른다.
